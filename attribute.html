Basic HTML & CSS Attributes

HTML Basic Attributes

Attribute Description Example
id Specifies a unique id for an element. 
<p id="intro">Hello World!</p>
class Specifies one or more class names for an element. 
<p class="text">Hello World!</p>
style Inline CSS styles for an element. 
<p style="color: red;">Hello World!</p>
title Specifies extra information when hovering over an element. 
<p title="Hello Tooltip">Hover over me!</p>
alt Alternative text for images. 
<img src="image.jpg" alt="Sample Image">
href Specifies the URL of a link. 
<a href="https://example.com">Visit Example</a>

Basic CSS Properties

Property Description Example
color Sets the text color. 
color: blue;
background-color Sets the background color. 
background-color: yellow;
font-size Defines the size of text. 
font-size: 16px;
margin Creates space outside an element. 
margin: 10px;
padding Creates space inside an element. 
padding: 20px;
border Defines a border around an element. 
border: 2px solid black;
